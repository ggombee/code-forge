# AgentOps 이전 계획 보관

아래 문서는 현재 검토 대상에서 제외하고 결정 과정과 요구사항의 출처를 보존한다. 현재 검토 문서는 [계획 안내](../../../docs/agentops/README.md)의 서비스 상세 계획과 통합 구현 계획이다.

| 문서 | 보존 이유 |
|---|---|
| [8월 자율 개발 루프 계획](./autonomous-development-loop-plan.md) | 실행 상태·증거·재시도 요구의 출처다. flow-toolkit을 필수 실행 엔진으로 두던 제안은 현재 기준이 아니다. |
| [08 도구 조합 재검토](./08.herdr-omp-hermes-qwen-control-plane-review.md) | Herdr·OMP·Hermes·Qwen의 초기 비교와 도구 조합의 판단 근거다. |
| [10 과잉설계 검증](./10.codeforge-thin-coordinator-overengineering-validation.md) | 이후 폐기된 기능 동결 판단과 작은 관찰 실험의 측정법을 보존한다. |

문서의 날짜·당시 상태·판정은 역사 기록이다. 이동에 따른 링크와 현재 기준 문서 안내를 갱신했으며 제품 요구사항을 새로 결정하지 않았다. 원래 위치와 내용은 Git 이력에서도 확인할 수 있다. 당시 검토 결과는 [검토 이력](../../../docs/agentops/evidence/)에 보존한다.
